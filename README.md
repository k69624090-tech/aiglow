# AIGLOW

AIGLOW is a beginner-friendly AI media website built as a static HTML/CSS/JavaScript site.

## Pages

- `index.html` - Home overview
- `articles.html` - Article list
- `article-chatgpt.html` - Article detail
- `videos.html` - Video page
- `gallery.html` - Image gallery
- `about.html` - About page
- `contact.html` - Contact page mockup
- `premium.html` - Monthly subscription page mockup
- `login.html` - Login page mockup

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Production

Current production deployment:

https://aiglow.vercel.app

This project is static, so it can be deployed for free on Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
